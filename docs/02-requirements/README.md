# Requirements

This folder contains requirements artifacts for the project.

## Files

- `requirements-overview.md` — requirement groups
- `functional-requirements.md` — detailed functional requirements
- `non-functional-requirements.md` — quality and technical requirements
- `use-cases.md` — major system use cases
- `user-stories.md` — user stories with acceptance criteria
- `requirements-catalog.md` — concise prioritized catalog
- `traceability-matrix.md` — initial business-goal traceability

## Next Step

The requirements will be mapped to:
1. domain/data model;
2. system architecture;
3. API contracts;
4. UI screens;
5. implementation modules;
6. tests.
