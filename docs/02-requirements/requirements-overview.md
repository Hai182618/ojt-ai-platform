# Requirements Overview

## 1. Purpose

This document provides the initial requirement groups that will be decomposed into detailed functional requirements, user stories, and acceptance criteria.

---

## 2. Requirement Groups

### RG-01 Authentication and Access Control
The system must provide secure authentication and role-based access.

### RG-02 Student Profile and Academic Data
The system must manage student information required for OJT operations and risk assessment.

### RG-03 OJT Plan Management
The system must support OJT plan creation, submission, review, approval, and rejection.

### RG-04 OJT Progress and Milestones
The system must track OJT progress, deadlines, and milestones.

### RG-05 Risk Prediction
The system must generate and store AI-assisted OJT delay risk assessments.

### RG-06 Risk Explanation
The system must provide understandable explanations of relevant risk factors.

### RG-07 Recommendation
The system must provide recommended intervention actions based on available risk context.

### RG-08 Intervention Management
The system must support creation, ownership, tracking, and closure of interventions.

### RG-09 Dashboard and Monitoring
The system must provide role-appropriate dashboards and monitoring views.

### RG-10 Reporting and Analytics
The system must provide operational OJT and risk reporting.

### RG-11 Administration
The system must provide user, role, and system configuration management.

### RG-12 Auditability
The system must preserve traceability for critical workflow events.

---

## 3. Traceability Principle

Detailed requirements will use stable IDs such as:

- FR-AUTH-001
- FR-STU-001
- FR-OJT-001
- FR-RISK-001
- FR-INT-001

These IDs will later be referenced by:

- API specifications
- UI screens
- source-code features
- test cases
- UAT scenarios
- requirement traceability matrix
